Magic Mouse 2024 (v3) Windows driver — scroll fix for PID 0323

Apple ships no Windows driver for the 2024 USB-C Magic Mouse, Bluetooth PID 0323. This free, MIT-licensed project restores two-finger scroll on Windows 10 and Windows 11 — the shipped route needs no Test Mode and covers v1, v2, v2-alt and v3. Pair it with Magic Tray for battery percentage in the tray.

What is shipped, and what is still in development?

The Apple-driver route is shipped and installable today. The KMDF route is development work only — no installable package, compiled .sys, or installer ships on this branch. Do not try to install the KMDF route from this branch.

Does Apple make a Windows driver for the 2024 Magic Mouse?

No. Apple's Boot Camp package has no entry for PID 0323, so Windows falls back to its generic HID mouse stack — clicks and cursor movement work out of the box, but nothing teaches Windows to keep the touch-surface scroll collection alive.

Why installing Boot Camp doesn't help either

Installing Apple's Boot Camp software does not rescue the older mice either: Apple's installer refuses to run on non-Apple hardware, and even when applewirelessmouse.sys is present on disk, Windows will not attach it to the mouse until something registers the driver as a lower filter on the device. That registration is exactly what this project's Apple-driver installer does — the approach sbagirici proved on Magic Mouse v1 and v2.

Why does Magic Mouse scroll stop working on Windows 11 after a Bluetooth reconnect?

Windows collapses the mouse's HID collections after a Bluetooth idle disconnect — this project calls the two states Mode A (working) and Mode B (broken). The cursor still moves and clicks still register, so the mouse looks healthy, but two-finger scroll is gone.

What DSM does, and why it doesn't self-recover

DeviceSetupManager (DSM) runs a property synchronisation pass on reconnect, and the device can come back in this reduced form. It does not self-recover: before this driver, the only ways back were a driver reinstall or re-pairing the mouse.

What does the Magic Mouse v3 Windows driver do?

The shipped Apple-driver route is a kernel-mode lower filter on the mouse's Bluetooth HID stack. The KMDF route is development work only on this branch, so it has no installable user path here.

  • Apple-driver route (v1-binary-patch/, v1.0.0, production ready) — registers Apple's own unmodified applewirelessmouse.sys as a lower filter. Because the binary is untouched and no catalog is installed, no Windows Test Mode is required. Scroll feel is Apple's own Mac-style translation, sensitivity fixed. Supports 0x030D, 0x0269, 0x0310 and 0x0323.
  • KMDF route (v2-kmdf-driver/) — development documentation only. No compiled .sys, installable package, or installer ships on this branch. Planned scope is PID 0x0323 with Test Mode, tunable scroll and automatic recovery.
How the Apple-driver installer registers the driver

The installer copies the unmodified binary to System32\drivers, creates an applewirelessmouse kernel service, adds that driver to the Bluetooth HID device's LowerFilters, then restarts the device so Windows re-enumerates it with the filter attached.

Install the shipped Apple-driver route. Do not combine it with unreleased KMDF work.

Which Magic Mouse do I have?

Check the Bluetooth product ID: Device Manager → Human Interface Devices → Apple Magic Mouse → Properties → Details → Hardware Ids, then read the PID_ value. The shipped Apple-driver route supports all four PIDs below.

How do I see Magic Mouse battery percentage on Windows?

Use the Magic Tray app — the shipped Apple-driver route does not read battery itself. The unreleased KMDF route is not available from this branch.

The 2024 Magic Mouse reports charge on HID Input report 0x90, collection COL02. Magic Tray reads it in userspace with a brief, temporary Mode A to Mode B flip, then flips it back.

How do I install the Magic Mouse 2024 (v3) Windows driver?

For the shipped Apple-driver route:

  1. 1

    Turn off Fast Startup

    From an elevated prompt: powercfg /h off, then reboot.

  2. 2

    Run the installer

    Download the repo and double-click v1-binary-patch/Install.cmd. It asks for Administrator itself, uses the bundled unmodified Apple driver, needs no PowerShell window or execution-policy change. No Test Mode — Secure Boot and memory integrity can stay on.

  3. 3

    Reboot

    A reboot finishes the job and two-finger scroll comes back.

The KMDF route is not currently installable. This branch contains development documentation only — no compiled driver, signed package, or installer. Do not follow KMDF installation instructions until a complete package is published.

The full sequence for the shipped route, including rollback, is on how to install the Apple-driver route.

Is this driver free, and how does it compare to Magic Utilities?

It is free and MIT licensed, with no subscription. Magic Utilities is paid subscription software; this project is not, and nothing here expires or stops scrolling when a licence lapses. Maintained by Revive Business Solutions / Lesley Murfin, not affiliated with Apple.

What money would buy for the KMDF route

Signing is the one thing money buys for the future KMDF route. That route is development work only on this branch; an EV certificate plus Microsoft attestation signing would be needed before a production package could load normally. The Apple-driver route sidesteps the problem because it redistributes Apple's own signed binary without touching a byte of it.
