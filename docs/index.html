Magic Mouse 2024 (v3) scroll on Windows

This repo is the kernel side for PID 0323 only. Apple never put that ID in Boot Camp. After Bluetooth idle, Windows can collapse HID collections (Mode A → Mode B): cursor lives, wheel dies. Magic Tray installs the KMDF package from here. The v1 patched applewirelessmouse.sys is research history, not the tray fallback.

Not v1 / v2

Magic Mouse v1 (030D) and v2 (0269) use the catalog-signed Boot Camp INF. This tree will not help those mice. See tealtadpole or Magic Tray’s Boot Camp action.
